| **Terminal workflow** | CLI workflows — explicit verification, scripting, and agent loops |
| **Enterprise/compliance** | managed IDE or extension workflows — filter by policy and deployment needs |

## What Changed in 2025-2026

- **The bottleneck moved** — writing syntax matters less; harness design, verification, and review matter more.
- **Context got harder, not easier** — big windows help only when context is selective and well-structured.
- **Specs beat vibes in production** — durable workflows now start with a spec, acceptance criteria, and a verification loop.
- **Subagents became normal** — modern workflows isolate search and research so the main implementation context stays clean.

## The Golden Rule

> **Start with tasks you already know how to solve.** This builds intuition for when the AI is right vs. hallucinating before you rely on it for unfamiliar territory.
