## Scope

This guide covers three things:

1. safe setup for AI coding tools
2. workflow and stack selection based on how the work is done
3. verification, context, and review patterns for AI-assisted engineering

It is not a live product database. Tool and model details change quickly; durable workflow guidance changes more slowly.

## Required Conditions

AI-assisted coding is more reliable when these conditions are present:

- output is checked with tests, builds, type checks, screenshots, or explicit expected results
- workflow shape matches the task type
- context is selective and relevant to the current task
- changes are small enough to review
- generated code is still reviewed by a human who can maintain it

## Verification Rule

> **Start with work you could solve on your own.** Familiar tasks make model errors easier to detect.
